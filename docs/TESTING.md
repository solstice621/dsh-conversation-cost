# 测试与验证

## 本地命令

```sh
npm ci --ignore-scripts
npm test
npm run check
```

无第三方测试依赖，不需要账号、网络服务或付费模型请求。`npm run check` 校验 JavaScript 语法、bundle 入口、公共数据和 npm 包文件清单。

## 自动测试覆盖

当前有 69 项测试：

- 四类 Token 独立计价，推理 Token 不重复相加；上下文分档包含缓存输入。
- 切换模型、不同渠道、API 金额和订阅等值；明确的零单价与缺价区分。

- DeepSeek 峰谷、周末和已有中国节假日日历；官方页面格式变化时保留旧价格。
- 重复事件去重、冷读与实时事件竞争、临时读取失败重试和 fork 继承排除。
- 回答逐轮隔离、多步骤合计、缺失用量归属，以及逐轮总计与会话总计一致。
- 客户端简洁标签、未计价不显示零金额、回答消息到轮次的绑定和明细范围。
- 公共价格刷新并发合并、磁盘缓存跨实例回读、离线保留和卸载时中止价格请求。
- 本地快照跨重启恢复、LRU/退出/durability checkpoint 保存、新用量增量更新、价格变化重估。
- 快照 allowlist、私有文件权限、损坏/超大/非法计数及日期的缓存自愈、并发保存和删除标记。
- 事件缺口、迟到通知、fork 边界、截断修复、静默会话校验、关闭期间的读取与 live snapshot 升级。
- 多实例文件锁、较旧写入拒绝、删除后迟到读取不得复活、残留锁有界失败且不偷取。
- 客户端缓存优先、快慢响应竞态、错误保留金额及待更新、点击重试、共享轮询和会话/unmount 隔离。
- 宿主 API 能力检查在任何价格初始化或路由登记前失败。

Host 测试使用临时目录和确定性日志；Client 测试通过 VM 执行真实模块工厂，验证组件输出。测试不会读开发者的真实 Harness profile。

## 验证边界

- 其他操作系统、其他 Harness 版本、真实订阅账单与按次工具计费尚未完成端到端验证。
- 未为每个价格目录条目逐一调用模型验证；缺价与数据漂移通过覆盖提示和缓存回退处理。
- 自动测试验证本插件的路由登记与行为；宿主完整 HTTP 认证链以已完成的实际桌面检查为依据。

## 目录结构

```text
lib/index.js              Host：会话日志读取、事件监听和认证接口
lib/cost.js               用量折叠、价格匹配、逐轮与会话汇总
lib/prices.js             公共价格同步、日历和缓存
lib/session-cache.js      私有用量快照、校验、文件锁和删除标记
lib/client.js             原生插槽、简洁 Cost 与明细弹窗
data/prices.json          可离线使用的公共价格/日历快照
test/                    确定性回归测试与最小定价页 fixture
scripts/check-package.mjs 语法与 npm 包验证
cordis.patch.yml          原生 bundle 声明
```
